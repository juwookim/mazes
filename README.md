# 실타래 미로

빨간 실을 풀며 출구를 찾는 브라우저 미로찾기 게임입니다.

**▶ 플레이:** https://juwookim.github.io/mazes/

설치할 것 없이 `index.html` 파일 하나로 동작합니다. 브라우저로 파일을 직접 열어도 됩니다.

## 게임 방법

- 왼쪽 위 입구에서 출발해 오른쪽 아래 초록 깃발까지 가면 탈출입니다.
- 지나간 길에는 빨간 실이 남습니다. 왔던 길로 되돌아가면 실이 다시 감깁니다.
- 막히면 **길 보기**를 누르세요. 현재 위치에서 출구까지의 길이 점선으로 표시됩니다.

### 조작

| 입력 | 동작 |
| --- | --- |
| `←` `↑` `↓` `→` / `W` `A` `S` `D` | 이동 |
| `N` | 새 미로 |
| `H` | 길 보기 / 숨기기 |
| 미로 판 스와이프 (모바일) | 이동 |
| 화면 아래 방향 버튼 (모바일) | 이동, 꾹 누르면 연속 이동 |

### 난이도

| 단계 | 크기 |
| --- | --- |
| 쉬움 | 10×10 |
| 보통 | 18×18 |
| 어려움 | 28×28 |
| 미궁 | 40×40 |

## 기능

- 시작할 때마다 새 미로 생성 (재귀적 백트래킹 알고리즘)
- 시간·이동 횟수 측정, 난이도별 최고 기록 저장 (브라우저 `localStorage`)
- 탈출 시 내 걸음 수와 최단 경로 걸음 수 비교 (BFS)
- 라이트 / 다크 모드 자동 대응
- 데스크톱과 모바일 모두 지원
